## 它解决什么问题

把本站设计稿里验证过的组件（卡片 / 徽章 / 热力图 / 时间线）抽成可复用的开源组件库，目标是：**零依赖、暗色优先、复制即用**。

## 设计原则

- Web Components + 原生 CSS 变量，不绑定任何框架；
- 设计令牌与官网同源（同一套 tokens.css）；
- 每个组件附带可交互 demo。
